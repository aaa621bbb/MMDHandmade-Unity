## 两条线的区别（别混淆）

| | 本仓库（Unity） | 另一个仓库（网页 Babylon） |
|---|---|---|
| 仓库 | `MMDHandmade-Unity` | `giant-step-caixiao` |
| 加载模型 | `PMXImporter.BuildUnityObjects` | `mmdRuntime.createMmdModel` |
| 骨骼权威 | `MMDTransformManager`（execution order 10000，LateUpdate） | babylon-mmd runtime |
| 单位 | `k_MMDUnitToUnityUnit = 0.08`（PMX ≈ 1.6 m） | 自定米制 |
| 文档口径 | **本文档集（Unity）** | 旧文档集（v2.0 系列，只对网页线有效） |

> 拿旧文档里的 `DynamicTexture` / `thin instances` / `onBeforeRenderObservable` 来 Unity 里照抄，一定错。
