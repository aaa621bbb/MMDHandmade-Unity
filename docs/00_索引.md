## 最容易踩的三个坑（每版都看一遍）

1. **缩放巨人 PMX → 衣服乱飞。** 她 `localScale` 永远 1，永远缩世界。
2. **相机 `nearClipPlane`（默认 0.3）和 `CharacterController.minMoveDistance`（默认 1mm）**
   → 缩放后的世界会表现为"什么都看不见""移动不了"。这两个是 Unity 侧的头号杀手。
3. **退出清理写不全** → 第二次进入越来越卡、画面变暗、帧率被锁 60。零残留是硬指标。
