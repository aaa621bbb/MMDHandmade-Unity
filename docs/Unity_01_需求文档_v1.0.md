## 0. 核心幻想（一句话）

> **我小到可以被随意踩死，而她甚至不必注意到我。**

**所有需求都必须能追溯回这一句。** 追溯不回去的，不做。

---

## 1. 三条设计铁律

1. **加存在感，不加系统。**
   只加三种东西：**尺度感**（让她更大更重更近）、**她的存在感**（她像个活人，不是追踪 AI）、**玩家的主动性**（玩家能玩她、玩城市）。
2. **这是玩具，不是工作。**
   **不做**：道具/消耗品系统、技能树、数值成长、每日任务、体力值、排行榜运营。
3. **每一版都要能自己上手玩 2 分钟，并回答一句："这比上一版好玩吗？"**
   答不上来，就不往下做，先把当前这个调对。

---

## 2. 明确不做（防止跑偏）

| 不做 | 原因 |
|---|---|
| **道具/消耗品**（烟雾弹、护盾、加速饮料、诱饵、投掷物…） | 会把玩法从"玩她"变成"玩道具栏"。**明确砍掉。** |
| 技能树 / 数值成长 / 等级 / 每日任务 | 玩具变工作 |
| 多玩家 / 联机 | 与核心幻想无关 |
| 玩家用自选 PMX（本版） | 巨人可换模型即可，玩家是程序小人 |
| 60 秒计分挑战 + 难度曲线（本版） | 玩法未定型前不做平衡 |
| lilToon 之外的美术插件化改造、URP 迁移 | 见制作文档 §0 铁律：**保持 Built-in RP** |

> ⚠️ 另有一份**已被否决的点子清单**（脚趾缝藏身、落地风压、踩扁弹回、胆子计分、震动分级、各类道具），
> 见 §8 版本记录。**不要重新加回来。**

## 3. 尺度（一切的前提）

| 角色 | 设定 |
|---|---|
| **她（巨人）** | 加载进来的 PMX，**`transform.localScale` 永远是 1**。她的体感身高 ≈ **30 m**（10 层楼） |
| **你（小人）** | 现实身高 1.7 m，在这个世界里只有 **脚踝以下** 那么高 |
| **比例** | ≈ **1 : 18 ~ 1 : 20** |

> **为什么必须这样**：UMT 在导入时按 `k_MMDUnitToUnityUnit = 0.08` 把 MMD 单位换算成 Unity 米 ——
> **一个标准 PMX 进 Unity 后身高约 1.6 m，就是真人高**。
> 而 Bullet 的弹簧参数是按"Unity 米制"标定的（`MMDPhysicsManager` 源码里写明做了 scale / scale² 补偿）。
> 你一旦缩放巨人 root，刚体惯量成倍变化，**弹簧立刻脱离标定区间 → 裙子头发当场乱飞**。
> → 正确做法：**缩世界**（把城市与小人放进一个统一缩放的根节点下）。详见制作文档 §1。

**验收**：小人站在街上，头顶大概到她**脚踝**；抬头能看到她整个人遮住天空。

## 4. 玩法模式（主菜单可切换）

| 模式 | 玩法 | 优先级 |
|---|---|---|
| **① 自由沙盒**（默认 / 新手引导） | 不判负。她真的不会踩死你。用来逛城市、看她、试操控、熟悉躲法 | **P0** |
| **② 生存逃脱** | 躲她追踩，存活计时，有结算 | **P0** |
| **③ 巨人模式（反转）** | **玩家操控巨人**走街，踩满街的小人；踩车会压扁、踩断路灯 | **P1** |
| **④ 拍照 / 摆姿** | 冻结她的 AI，自由机位 + 给她摆姿势，与城市同框出片（见 `Unity_摆姿势模块_方案_v0.1.md`） | **P2** |

> **①必须做，而且要做在②前面。** 它是唯一能让第一次上手的人"看清楚这游戏到底有什么"的模式。
> 先让人能看见、能走动，才谈得上好玩。

## 5. 内容清单

### 5.1 她：把她做成一个活人（**本项目最稀缺的东西**）

一个只会追你的 AI 是**怪物**。一个会打哈欠的巨人是**角色**。

**5.1.1 行为状态机**
`巡游 → 发现你 → 追 → 逼近抬脚 → 踩下 → 收脚 → 继续`，中间穿插**搜索**与**日常**。
每个状态有 enter/exit + 最小持续时间 + 过渡时长，**时间驱动，不用帧数**。

**5.1.2 她的日常（P1）** —— 她不是永远在追你：
- 坐下来休息，把脚伸到你面前（那只脚本身就成了路障）
- 低头看手机（**你趁这时候溜过去**）
- 打哈欠、伸懒腰、跺脚取暖
- 对着橱窗看自己的倒影（顺便照到躲在她身后的你 = 被发现的戏剧瞬间）

> 玩法作用：提供**节奏起伏**。她休息 = 你的安全窗口；她一站起来 = 危机重启。

**5.1.3 视线与听觉（P0，潜行的地基）**
- **视线锥**：她在看哪，你一眼能读出来。锥内 = 看得见你。
- **听觉**：你跑得快、踩到碎屑/水洼、撞翻垃圾桶 → 发出声音 → 她转头。
- **搜索行为（P1）**：找不到你时不立刻重置，而是「原地张望 → 走向最后目击点 → 低头翻找藏身处」。

**5.1.4 换鞋（P1，最省的内容扩展）**

| 鞋 | 玩法差异 |
|---|---|
| 高跟鞋 | 落点极小、压强极高（判定半径小但必杀），落地「咔」一声 |
| 长靴 | 判定半径大、闷响、地鸣重，她显得更重 |
| 运动鞋 | 落地几乎没声音 → **潜行难度暴涨**（你听不到她来了） |
| 赤脚 | 落地有肉感的声音；走过水洼会留下脚印 |

> 同一套动作、同一套模型，**换一双鞋就是换一套玩法**。

**5.1.5 她的情绪（P1）**
- 有「**注意力 / 怒意**」两个隐状态；你贴得太近、活得太久，她会更凶 —— **难度是剧情化的，不是菜单里的**。
- 玩家能感知但看不见数字：靠**姿态、音效、心跳**传达。

**5.1.6 动作库（P1）**
踩 / 碾（脚掌前后滚）/ 踢 / 抓起来看 / 蹲下伸手指戳 / 吹气。

### 5.2 城市：一个可以玩的玩具，不是布景

**5.2.1 分区（P0 做 2 个，P1 做齐）**
商业街（高层 + 玻璃幕墙 + 霓虹招牌 + 底层商铺）／住宅区（低矮公寓 + **阳台、晾衣杆、空调外机、防盗窗** —— 这三样是"生活感"的关键）／公园（草地、树、长椅、喷泉、儿童设施）／工地（塔吊、围挡、钢筋堆、脚手架、**可攀爬点**）／水岸（河、桥、护栏、泊船）。

**5.2.2 地标（P1，1~2 个）**
电视塔 / 钟楼 / 大商场。作用 = 远景锚点 + 方向感 + 出片。

**5.2.3 街道家具（P0 ≥ 8 种）**
路灯、红绿灯、斑马线、车道线、护栏、公交站牌、报刊亭、电话亭、自动售货机、长椅、垃圾桶、消防栓、井盖、交通锥、路障、广告灯箱、霓虹招牌、遮阳棚、无障碍坡道。

> 这些不是装饰，是**玩法资源**：垃圾桶可藏身、售货机可推倒挡路、消防栓被踩会喷水柱、交通锥可以被踢飞。

**5.2.4 车辆（P1）**
路边停车（**可被踩扁成"纸箱"、可被踢飞**）+ 少量行驶车辆。
> **车被踩扁的瞬间是这个游戏最好的"尺度感演示"**，比任何 UI 数字都直观。

**5.2.5 连锁破坏（P1，城市成为玩具的关键）**

| 触发 | 连锁 |
|---|---|
| 踩扁一辆车 | 车变成饼 → 饼能被踢飞 → 撞到别的车又碎一片 |
| 踩断消防栓 | 水柱冲天 → 把附近的小人（**包括你**）冲走 → 地面变湿打滑 |
| 踩塌楼顶 | 碎石从天而降 → 变成新路障 → 挡住你的逃跑路线 |
| 踩过水洼 | 溅起的水花把你浇翻 |
| 踩到电线杆 | 电线崩断 → 甩出电弧与火花 → 半条街的灯闪一下 |

**5.2.6 小人 NPC（P1）**
街上跑着小人 NPC。他们看到她会**尖叫四散** —— 而**逃散方向暴露你的位置**：她顺着人群跑的方向看过来。
> 人群从"装饰"变成"会出卖你的东西"，玩家会开始主动避开人多的地方。

**5.2.7 动态元素（P1/P2）**
飞鸟群（被惊起飞走）、气球、飘动的旗与横幅、随风滚的纸片落叶。
> 静态城市是"模型"，有动态才叫"活的城"。

**5.2.8 细节层（P2）**
地面水洼、污渍、裂缝、墙面涂鸦、褪色海报。

**5.2.9 垂直空间（P1）**
地下通道 / 地铁口 / **可达楼顶**。有垂直空间，"躲"才有策略。

---

### 5.3 你：让玩家能玩，而不是只有跑

**5.3.1 基础动作（P0）**
走 / 跑 / **闪避翻滚**（短冲刺 + 短暂无敌帧 —— 躲踩的核心手感）。

**5.3.2 进阶（P1）**
跳、蹲下（缩小被踩判定）、被震到踉跄（她靠近时的被动演出）。

**5.3.3 藏身（P0，潜行的核心）**
钻进垃圾桶 / 躲到车底 / 进地下通道 / 跑进楼内 → 她**失去目标并进入搜索**。
> 这一条把玩法从"体力活"变成"斗智"，**强烈要求做**。

**5.3.4 爬上她（P1，同类游戏的核心幻想）**
从楼顶/脚手架跳上去，或沿着她的**鞋带、鞋跟、裙摆**往上爬 → **你被带走了**。她在城里走，你在她脚背上。
> 玩法上这是一个**会自己移动的关卡**。从上面摔下来 = 一次明确的伤害。

---

### 5.4 反馈与节奏

**5.4.1 局内播报（P1）**
像体育解说一样弹字：「擦身而过！」「她发现你了！」「完美闪避 ×3」。成本极低、爽感极高，**性价比第一**。

**5.4.2 慢动作特写（P1）**
- **不要只在"被踩中"才慢动作**（那是惩罚）—— **擦身而过时也要慢**，让玩家看清那只脚离自己有多近。
- **机位要低**：从街角**贴地仰拍**那只压下来的脚，背景是她遮住天空的身体。
  > 这个镜头本身就是这个游戏最值得截图的一帧。
- 技术注意：`Time.timeScale` 会同时影响 UMT 的骨骼求解与物理（用 `Time.deltaTime`），**这正是想要的**；
  但**退出时必须还原**（见制作文档 §10 全局状态还原清单）。

**5.4.3 心跳（P1）**
心跳音随"她的注意力"加速。被她盯上时，心跳几乎盖过 BGM。
> **最便宜的紧张感发生器**：不需要任何新内容，只是把已有的距离映射成音频。

**5.4.4 成就 / 里程碑（P2）**
首次贴脸躲过 / 无伤活满 60 秒 / 靠藏身处脱险 3 次 / 亲眼看着她踩扁 5 辆车。

---

### 5.5 氛围

- **时间档（P0 基础 → P1 做全）**：清晨 / 正午 / 黄昏 / **夜晚（霓虹 + 窗户点亮）**。夜景性价比极高，**建议默认黄昏或夜晚**。
- **天气（P2）**：晴 / 雨（地面湿反光 + 雨丝）/ 雾。
- **音效（P0 起步 / P1 做全）**：
  - 她的脚步 —— **要有方位感与由远及近的层次**（这是压迫感的一半）
  - 落地重低音 / 地鸣 / 玻璃碎裂 / 警报 / NPC 尖叫
  - 危险时 BGM 动态切换（安全 → 紧张 → 被追）

> 内容量不是难点，**能稳定叠加而不崩，才是这个项目真正的难点。**

## 7. 验收线（总）

**上手 30 秒内**
1. 第一帧就能看见城市与地面（不是黑屏、不是纯色）。
2. 摇杆能动 —— 按下去人就走，不卡不飘。
3. 抬头能看到她的全身，她比整条街都高。

**上手 2 分钟内**
4. 你能读出她在看哪里（视线锥 + 姿态），并且能利用这个藏起来。
5. 被踩中时有明确的演出与反馈，且**不会被迫重开**（沙盒模式下不判负）。

**整体**
6. 她的影子压在街上；她走过时地会震、声音由远及近。
7. 不看 HUD 截一张图，别人能认出"一个巨人在城市里"，而不是"一堆盒子"。
8. 退出这个模式后，回到原来的 MMD 播放界面**跟没进过一样**（零残留）。
9. 真机 60 FPS；`SetPass calls` / `Batches` 在制作文档 §9 的预算内。
